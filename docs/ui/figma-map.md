# Bản đồ màn hình Figma ↔ UC ↔ code

File Figma: [Personalized English Learning](https://www.figma.com/design/1lvmT8y6aAhsOYil7blaXE/Personalized-English-Learning) (fileKey `1lvmT8y6aAhsOYil7blaXE`). Nghiệp vụ theo [`docs/srs/SRS_1.md`](../srs/SRS_1.md) (SRS v4.3). Lập ngày 16/11/2026 từ `get_metadata` của từng section.

- Mỗi dòng là **một màn**. Cột *Frame chính* là frame dựng theo; cột *Biến thể* là frame trạng thái của cùng màn (lỗi, đã chọn, đúng/sai, sheet thu gọn…).
- Dòng không có frame chính là màn SRS yêu cầu nhưng Figma chưa có, sẽ dựng từ component sẵn có; xem GAP tương ứng trong [`design-gaps.md`](design-gaps.md).
- *Đường dẫn code*: điền khi dựng xong. *Trạng thái*: `chưa làm` → `đang làm` → `cần duyệt` → `xong`.
- Cập nhật file này trong cùng PR với màn tương ứng (lệnh `/figma-screen`).
